# i18n

> Rule: `.cursor/rules/i18n.mdc`

| Layer                   | Owns                                                                                                            |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- |
| `packages/i18n`         | `messages/<locale>/*.json`, locale config, `loadMessages`, `formatDate` / `formatNumber` / `formatRelativeTime` |
| `apps/web/src/i18n`     | `request.ts` (cookie locale), `setLocale`                                                                       |
| App UI + Server Actions | `getTranslations` / `useTranslations` — no hardcoded product copy                                               |

URLs stay English in `*-routes.ts`. Labels come from message namespaces.

## Locale

- Cookie: `BS_LOCALE` (`localeCookieName`)
- No `[locale]` segment, no middleware, no URL prefix
- `lang` / `dir` on **root layout only**
- Better Auth API errors: `@better-auth/i18n` in `packages/auth` (same cookie, built-in `en` / `fa`). Do not duplicate auth error codes in `messages/`.

Namespaces: `common`, `auth`, `dashboard`, `account`, `badges`, `tables` under `packages/i18n/src/messages/en/`.

Do not put translated strings inside `'use cache'` unless locale is part of the cache key. Prefer message **keys** in cached config; resolve in the component.

## Add a locale

1. Mirror `messages/en/*.json` under `messages/<locale>/`
2. Add the locale in `packages/i18n/src/config.ts`
3. Add a label in `apps/web/src/components/locale-switcher.tsx`

`LocaleSwitcher` renders when `locales.length >= 2`. RTL: `getLocaleDirection('fa')` → `rtl` on `<html>` + `DirectionProvider`.

- Server / client: `formatDate` / `formatNumber` / `formatRelativeTime` from `@repo/i18n` with `getLocale()` / `useLocale()`
