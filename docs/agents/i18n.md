# i18n

> Rule: `.cursor/rules/i18n.mdc`. **Messages** live in `@repo/i18n`. Apps wire catalogs through `next-intl`.

## Layout

| Layer               | Owns                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------- |
| `packages/i18n`     | `messages/<locale>/*.json`, locale config, `loadMessages`, `formatDate` / `formatNumber` |
| `apps/web/src/i18n` | `request.ts` (cookie locale), `setLocale` server action                                  |
| App UI              | `getTranslations` / `useTranslations` — no hardcoded product copy                        |

**URLs stay English.** Route builders remain in `*-routes.ts` (`/dashboard`, `/login`, …). Labels come from message namespaces, not route SSOTs.

## Locale (v1)

- Cookie: `BS_LOCALE` (see `localeCookieName` in `@repo/i18n`)
- No `[locale]` segment, no middleware, no URL prefix
- `lang` / `dir` on **root layout only** — `DirectionProvider` + `NextIntlClientProvider`
- Better Auth API errors: `@better-auth/i18n` in `packages/auth` reads the same cookie (built-in `en` / `fa` dictionaries). UI copy stays in `messages/` — do not duplicate auth error codes there.

## Message namespaces

```
packages/i18n/src/messages/en/
  common.json
  auth.json
  dashboard.json
  account.json
  badges.json
  tables.json
```

Use `useTranslations('dashboard')` or nested keys like `dashboard.nav.sidebar.account`.

## Caching

Do **not** put translated strings inside `'use cache'` unless locale is part of the cache key/tag. Prefer message **keys** in cached config (e.g. sidebar nav) and resolve with `useTranslations` in client components.

## Add a locale (e.g. `fa`)

1. Mirror `messages/en/*.json` under `messages/fa/`
2. Add `'fa'` to `locales` in `packages/i18n/src/config.ts`
3. Add label in `LocaleSwitcher` (`apps/web/src/components/locale-switcher.tsx`)
4. `LocaleSwitcher` renders when `locales.length >= 2`; `setLocale` + `router.refresh()` updates cookie and direction

RTL: `getLocaleDirection('fa')` returns `rtl` — root layout sets `dir` on `<html>` and `DirectionProvider`.

## Formatting

- Server: `formatDate(value, await getLocale())` via `@/lib/format-date`
- Client: `useLocale()` + `formatDate` or `formatNumber` from `@repo/i18n`
